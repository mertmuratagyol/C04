42 C Piscine - C04

This repository contains my solutions for the C04 project of the 42 Kocaeli C Piscine.

About the Project

The C04 project focuses on advanced string handling and numeric operations in C. It introduces fundamental functions for calculating string lengths, displaying strings and numbers, and converting strings to integers while strictly adhering to the Norm coding standards.

Exercises

* Ex00: Displays an integer on the screen (ft_putnbr.c)
* Ex01: Displays a string on the screen (ft_putstr.c)
* Ex02: Computes and returns the length of a string (ft_strlen.c)

Technologies & Rules

* Language: C
* Compiler: gcc (with -Wall -Wextra -Werror flags)
* Standard: 42 Norm (Norminette compliant)
